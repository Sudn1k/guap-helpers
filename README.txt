Приложение группы ГУАП — кликабельный прототип
================================================

Как открыть
-----------
Откройте index.html двойным щелчком — он запустится в браузере, сервер не нужен.
На странице список всех экранов; «Начать со входа» проводит по всему пути.
Можно выложить папку на любой статический хостинг (GitHub Pages, Netlify и т. п.)
и открыть ссылку на телефоне — экраны покажутся во весь экран.

Что где лежит
-------------
index.html              — список всех экранов по разделам
screens/*.html          — по одной странице на каждый экран (разметка в <template>)
css/app.css             — общие стили и рамка «телефона»
js/dc-lite.js           — маленький движок: подстановки, условия, списки, клики, состояние
js/components/*.js      — логика каждого экрана (данные-примеры, переключатели, фильтры)
img/app-icon.svg        — значок приложения (фавикон)

Заметки
-------
• Шрифт Roboto грузится из Google Fonts; без интернета будет Arial.
• Иконки и обложки нарисованы внутри разметки (SVG), отдельных растровых картинок в макетах нет.
• Все имена, расписание, задания и курсы — выдуманные примеры.
• Неофициальный студенческий проект, не связан с администрацией ГУАП.
